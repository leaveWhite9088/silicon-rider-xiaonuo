# 排行榜 · silicon-rider-xiaonuo（v1.3.1）

> 每次评分由 `src/scoring/score_run.py` 自动追加；D 层（中心追加评审日志）由评审管道回填。
> 本榜对应 **`xiaonuo-v1.3.1` 口径**（供给按模拟时间、B2 端到端）。版本号不同的成绩分开归档，不混排。

## 赛制口径

| 维度 | 规则 |
| --- | --- |
| 班次 | 480 分钟（06:00–14:00，时钟 360 → 840，840 后不再执行动作） |
| 供给 | 每 **5 个模拟分钟** 生成 1–3 张新单；查询不推进时间，因此刷查询不出单 |
| 时限 | `deadline = 接单时刻 + timeLimit` |
| 轮数 | 上限 400 |
| 计时 | B2 用**端到端**（选手开始 → 结果落盘）；`t0` 由选手开始前自记，命令传入或进程启动时间均有效 |
| 种子 | 对模型保密、对裁判公开；只落 sha256 承诺，评分核对；每批 3 个种子报均值 ± 极差 |
| 代打 | 允许写脚本，代价是端到端时间（直接压低 B2） |

## 计分

`A30（净利/锚）+ B15（无效调用 5 + 端到端耗时 10）+ C25（约束 9 + 状态 8 + 路径 8）+ D30（事实卡评审）`

锚值见 `configs/benchmark.json → scoring.anchor_yuan`（默认 350；换种子必须用 `tools/bounds.mjs` 重标）。
