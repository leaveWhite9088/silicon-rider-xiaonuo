## 赛制口径

| 维度 | 规则 |
| --- | --- |
| 班次 | 480 分钟（06:00–14:00，时钟 360 → 840，840 后不再执行动作） |
| 供给 | 每 **5 个模拟分钟** 生成 1–3 张新单（11:30–13:00 ×3，空间聚簇）；查询不推进时间，因此刷查询不出单 |
| 速度 | 行驶速度 ×2（60/50/40/30 km/h，≈1 分钟/km）；取货 2 / 送货 1 / 换电 1 分钟与 2%/km 电耗不变 |
| 时限 | `deadline = 接单时刻 + timeLimit`；timeLimit 按 0.5 收紧（下限 12 分钟），同时决定订单在库寿命 |
| 轮数 | 上限 400 |
| 计时 | B2 用**端到端**（选手开始 → 结果落盘），`t0` 由选手开始前自记，命令传入或进程启动时间均有效 |
| 种子 | 对模型保密、对裁判公开；只落 sha256 承诺，评分核对；每批 3 个种子报均值 ± 极差；换版本必须换新种子 |
| 代打 | 禁止脚本代打：只允许逐轮手动玩，违规成绩无效；`play.mjs --policy` / `harness.mjs --policy` 仅供开发调试 |

## 计分

`A30（净利/锚）+ B15（无效调用 5 + 端到端耗时 10）+ C25（约束 9 + 状态 8 + 路径 8）+ D30（事实卡评审）`

- B1/C1/C2/C3 在原档位节点之间连续过渡（满分可达 100%）；B1/B2 只在 A < 15 时才被 A 封顶。详见 `docs/scoring.md`。
- 锚值见 `configs/benchmark.json → scoring.anchor_yuan`（当前 700，暂定；首批实测后用 `tools/bounds.mjs` 与实测净利重标）。
